# Duelist Character Exploration V1

Purpose: generate the first pressure character exploration set

## Inputs

- Duelist brief
- forward-leaning motion constraints
- current visual profile target: sprite
- select-screen portrait requirements

## Outputs

- concept sheet
- strong pose sheet
- dash or chase pose reference
- launch and dunk pose reference
- portrait candidate

## Workflow notes

- bias for speed and aggression
- keep the motion language clean
- preserve anchor points for a sprite pipeline
- avoid motion blur that destroys body shape

## Cleanup notes

- align silhouette to stable frame bounds
- keep the portrait sharp and readable
- reject any pose that looks passive or defensive
