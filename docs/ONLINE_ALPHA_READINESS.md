## Mandatory exit gates

1. `npm run alpha:local-gate` and `npm run alpha:local-integration` pass from a clean checkout; their component commands remain separate CI steps for useful failure diagnostics.
2. All database migrations pass both static compatibility checks and `gw.rollback-schema-compatibility.v1` against the exact previous deployable build from a clean checkout.
3. Auth ownership/abuse smoke, ranked online smoke, two-client auth/session smoke, API process-replacement smoke, concurrent two-instance smoke, and PostgreSQL interruption smoke pass in staging.
4. A 30-minute two-client network soak stays inside the agreed disconnect, packet-loss, resync, and rollback-depth limits.
5. `npm run ai:balance-gate` and `npm run ai:alpha-readiness` pass in CI; a human flow review still approves the release candidate.
6. Every alpha character package passes schema, deterministic checksum, frame-bound, asset-budget, required-file readiness, and implemented-profile QA without fallback estimates.
7. Vanguard and Duelist have readable idle, movement, launch, dunk, defensive, helpless, and recovery presentation at gameplay scale.
8. A canary deploy, drain, resume, and rollback rehearsal is recorded against the intended hosting environment.
9. Public matchmaking remains disabled; only allow-listed accounts/builds can enter the alpha.

Run `npm run alpha:config-audit -- <uncommitted-combined-provider-env> [report-path]` before starting a hosted canary. The positional form is intentional because the root npm workspace wrapper consumes nested named flags. This is a local static audit and consumes no Neon, Render, Cloudflare, Steam, or TURN traffic. The provider snapshot remains uncommitted and the report records only check status, never secret values.

Development and repeated verification are local-first. Balance batches, replay review, production builds, browser visual checks, API integration, PostgreSQL interruption, process replacement, multi-instance coordination, and forced coturn relay all run against loopback services before any hosted rehearsal. Provider compute is reserved for the irreducibly remote exit evidence: real Steam verification, two separate networks/devices, hosted TURN, provider database failover, and one canary/rollback rehearsal after the exact release candidate has passed every local gate. API-targeting smoke scripts require an independently configured exact hostname, database identity, and deployment environment before the first request; hosted targets require HTTPS, redirects are rejected, every identity request is bounded, and production is always refused.

Production defaults to `closed`. Alpha entry requires `MATCHMAKING_ACCESS_MODE=allowlist` plus non-empty account and exact-build allowlists. `MATCHMAKING_MAX_RESIDENT_TICKETS=64` bounds the current full-snapshot coordinator independently of allowlist size and retained-ticket churn; existing tickets and session recovery remain available at capacity, while only new admission is refused. Queue joins and private-room create/join paths enforce the same access policy; rollout health checks inspect only mode, counts, and the configured capacity, never the allowlist values.

## Current gameplay-loop evidence

The previous `online-alpha-flow-v7` run passed broad aggregate guards while still flagging every reached Chase round. Threshold v8 closes that false-green gap: after at least 12 reached rounds per direction, it gates the Watch-plus-Blocked ratio for Commitment and Chase. The first local `ai-regression-flow-v8` run correctly fails rather than presenting the current loop as alpha-ready. The useful evidence is how rounds transpire, not which AI class wins:

- Both directed pairings resolve most sampled rounds rather than remaining indefinitely at point-blank range.
- Timeout ratio, round duration, physical-contact share, contact-episode p90/maximum duration, pressure duration, point-blank occupancy, neutral-reset cadence/conversion, average sustained-neutral duration, exchange resolution/reset quality, brief exits, unresolved pressure, and helpless time are gated independently for each direction.
- Every sampled round produced dunk attempts, p90 pressure sequences stayed below 17 seconds, and both agents averaged more than five accepted tactical action types.
- Launch-to-dunk conversion and delay, zero-fuel finish starts, qualified finish completion, launch-break reaction timing, accepted/rejected inputs, action entropy, dominant-action share, repeated-action streaks, and timeout-tail replays expose unfinished loops such as fighters rubbing together, instantly spending every escape, endlessly chasing, or starting finishes that never land.
- Repeat clashes, rapid post-clash launch, immediate re-launch, failed control-return resets, and carried brief re-entry are evaluated only after their evidence denominator is large enough. Sparse events remain visible without being converted into a misleading pass or failure.
- AI set outcomes remain in reports only as context for AI decision-making and kit reachability. They are not treated as proof of human matchup balance or as a release gate.

The current balancing priority is the **shape of play**, not class parity. A candidate must first demonstrate readable movement through Neutral -> Commitment -> Exchange -> Separation -> Chase -> Finish, with real decisions between contacts and enough control-return agency to avoid the old contact-lock loop. Class win percentage is useful only after those conditions hold, and only as a prompt for replay review or human playtesting. The Balance Lab is deliberately a manual tuning surface: it preserves fixed seeds, packages, scenario state, AI policy, exact inputs, and causal replay windows so a designer can change one control, compare the same situations, and decide whether the result is actually more legible and enjoyable.

The latest fast local designer batch generated 28 checksum-verified review replays and identified **Chase** as the shared bottleneck: 10 Blocked, 32 Watch, and 2 Observed samples among 44 rounds that reached the stage across four directed difficulty/matchup profiles. This is not a class-strength or release score. It points the next manual pass toward post-control agency, durable reset creation, first accepted action after control return, and launch-to-finish readability.

Package-driven dunk pursuit removed the previous failure where launched targets left the hit volume during long startup. Deterministic super-boost recommit memory now prevents repeated super boost from replacing the rest of an AI fighter's tactical loop. After the player-order audit, the current 12-set-per-direction Veteran run is exactly mirrored and reports no timeouts across 50 rounds, 11.12% physical contact, 36.77% point-blank occupancy, 54.39% pressure occupancy, 15.28 neutral resets per round, 79.6% resolved exchanges, 62.3% exchange resets, and 4.77s p90 pressure sequences. The mirrored zero-fuel funnel records 10 Vanguard finish starts with 6 completed wins and 58 Duelist starts with 44 completed wins. Those measurements rule out the old indefinite body-lock and missing-finish failures in this sample, but frequent short collisions and the neutral/exchange/chase rhythm still need replay-led judgement. Human observation remains required, especially for meaningful retreat, whiff punishment, and finish clarity. The different funnel frequency is a specific AI/kit pipeline to inspect, not a reason to tune toward a target class win percentage.

The alpha command gates Cadet and Veteran together, so the local-menu default cannot regress while only the harder controller is exercised in CI. The historical v7 run covered all four directed profiles across 102 rounds with no timeouts: 10.83% physical contact, 36.55% point-blank occupancy, 54.07% pressure occupancy, 16.04 neutral resets per round, 80.2% resolved exchanges, 64.8% exchange resets, and 5.18s p90 pressure sequences. Vanguard completed the finish path in both difficulties, while Chase remained flagged in all 102 reached rounds. Cadet and Veteran set winners remain deliberately informational rather than a tuning target; v8 must pass the stage-level limits before this evidence can support an alpha decision.

The v8 post-control pass added a replay-compatible steering control without changing that baseline. It keeps tactical counters available and prevents Duelist's auto-target dash from cancelling the experimental steering window. Matched eight-frame steering and reserve-aware natural-recovery reset candidates were rejected: they lowered some immediate re-launch or Blocked Chase counts but reduced durable reset quality and failed qualified Vanguard finish completion. Both controls therefore remain zero-default local Balance Lab tools; no Arcade, Online, Ranked, or human mechanic was changed from an attractive isolated metric.
